# Technical Feasibility and Budget

## Technical feasibility

- Stack is JavaScript/TypeScript end-to-end, suitable for rapid iteration.
- SQLite for dev; Prisma allows Postgres migration.
- Metaverse is vanilla Three.js, preserved.

## Budget (prototype)

- Hosting: low-cost VPS or PaaS.
- Domain: annual.
- Database: managed Postgres when scaling.
- Email: transactional provider.
- Storage: object storage for files.
- Monitoring: free/low-cost tier.

## Notes

- Figures are estimates; actual costs depend on usage and provider pricing.
