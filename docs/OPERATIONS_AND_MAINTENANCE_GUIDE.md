# Operations and Maintenance Guide

## Operations

- Health endpoint: `GET /api/health`.
- Logs: console + structured API errors.
- Monitoring: local health checks; external APM pending.

## Maintenance

- Daily: backup verification.
- Weekly: issue review.
- Monthly: dependency/security review.
- Quarterly: restore test.

## Incident workflow

- Detection → Assess → Contain → Revoke → Recover → Verify → Document.
