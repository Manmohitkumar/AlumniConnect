# Admin Guide

## Access

Admin accounts are provisioned server-side only; no public registration.

## Provisioning

Use Admin dashboard -> Provision tab, or `/api/admin/users/provision`.

## Universities

Manage institutions in Admin dashboard -> Universities tab.

## Verification

University reps verify students/alumni in the University portal.

## Audit

Review `/admin/audit` for state-changing actions.

## Announcements

Send in-app notifications to roles.
