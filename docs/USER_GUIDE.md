# User Guide

## Registration

Students and alumni self-register at `/register`. Verify email via the provided link.

## Login

Use your portal: `/student/login`, `/alumni/login`, etc.

## Profile

Complete profile and request university verification if applicable.

## Challenges

Browse `/challenges`, join, submit projects, receive feedback.

## Mentorship

Discover mentors, send requests, schedule sessions.

## Events

Register for events from the events page.

## Metaverse

Optional 3D hub at `/metaverse/index.html`; platform works without it.
